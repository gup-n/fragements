## 视觉实施方向

延续已批准方案 A，而非新建第三套产品：默认白纸+石墨+克制青绿，墨水保持中性色；不加渐变、纹理、装饰阴影或庞大组件库。

共用纯 UI tokens 已由Lead创建并从theme导出：

- `SPACE.xxs/xs/sm/md/lg/xl/xxl` = 4/8/12/16/20/24/32。
- `TYPE.display` 28/40/700，heading22/30/700，title18/26/600，body15/24/400，reading17/30/400，label13/20/600，meta12/18/400，caption11/16/500。使用方式：`{...TYPE.body, color:c.text}`，保留系统缩放。
- `surfaceStroke(metrics)`：普通模式装饰边线0.5，墨水用明确的strokeWidth。点击/选中/焦点依旧明确，不把全部边线抹掉。
- `navigationLayout(width,fontScale)`：用于独立导航行的窄屏布局，不改变导航路径。
- 继续使用旧Palette字段和ThemeMetrics结构，旧主题/测试/API兼容，不用style作为组件key。

实际改动：标题与导航分行、四入口等宽；记录输入像明确的书写面板而非一圈密集工具框；聊天开放正文、输入与scope/状态分层；文档清晰列表标题/摘要、回顾明确切换；设置每模块只一入口、当前值换行、不删新备份功能。阅读页增加可读层级，不破坏原件、引用和查找。
